# Отчёт ЛР1

Текущее выполнение: [REPORT.md](REPORT.md).
Утверждённый объём: [LAB1_PLAN.md](../../docs/LAB1_PLAN.md).
Малый e2e не завершает всю ЛР1: полная Portal, глобальный сбор и сравнительные
замеры следуют после обязательного просмотра результата пользователем.

После реализации: соответствие пунктам задания, источник и область сбора,
архитектура, обоснование трёх сервисов, описание DAG/ODS, реальные результаты,
методика и таблицы/графики сравнения, выбор хранилища, инструкция демонстрации.
Секреты, полный raw и большие бинарные выгрузки не публиковать.
Пока это место для отчёта, а не утверждение о выполнении ЛР1.
