# Воспроизводимое сравнение трёх ODS

**Историческая методика для прежней схемы.** После перехода на entity-v2
старый benchmark.py и CSV не подтверждают производительность нового формата.
Проверки Half-Life/Minecraft smoke находятся в REPORT.md; финальное сравнение
entity-v2 с тремя изолированными повторами ещё нужно выполнить.

Вход — объединение проверенных metadata/runs/players пакетов Half-Life
`half-life-full-001`, с устранением совпадающих логических ключей. Старые
исследовательские выгрузки не используются. SHA-256, размеры, счётчики,
100 фиксированных run ID и фильтр записываются в `input.json`.

Запуск после завершения активных DAG:

```powershell
docker compose exec scheduler python -u -m speedrun_etl.benchmark --collection half-life-full-001
```

Модуль делает три повтора в новых `test_bench_*` namespaces. Порядок сервисов
чередуется. Схемы и индексы создаются до отсчёта. Тестовые данные сохраняются
для проверки, production ODS не изменяются. Общая блокировка источника
исключает HTTP-сбор во время измерений; DAG перед началом должны завершиться.

CSV содержит время загрузки **вместе с проверкой чтением и восстановления**, а
не только скорость INSERT; повторную идемпотентную загрузку; чтение истории и
последнего наблюдаемого состояния 100 run ID; выборку game/category/status.
При чтении состояния используется история ID и payload последнего наблюдения.
Все результаты чтений сверяются по digest. Для S3 фильтрация выполняется
клиентом по объектам префикса run; PG/Mongo выполняют фильтр на сервере.
Каждое чтение проходит трижды. Первый проход не объявляется холодным кешем.

Объём PG — `pg_table_size + pg_indexes_size` только тестовой схемы ODS;
Mongo — `storageSize + indexSize`, отдельно `dataSize`; Garage — сумма
размеров объектов тестового префикса. Последняя величина не равна физическому
размеру Garage volume. Логический объём общего JSON-входа одинаков и указан
отдельно. Метаданные Airflow и контрольная БД исключены.

Результаты: `/opt/airflow/state/benchmarks/<timestamp>/measurements.csv`,
`input.json`, `completed.json`. После копирования в каталог отчёта:

```powershell
uv run --with matplotlib reports/lab1/plot_results.py reports/lab1/measurements.csv
```

Это методика. Пока нет `completed.json` и реального CSV, сравнительные числа,
графики и окончательный выбор основного ODS не считаются полученными.
