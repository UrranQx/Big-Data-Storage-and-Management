# Проверки рабочего приложения

Тесты будущей реализации ЛР1: API-клиент, покрытие, повторы, загрузчики и
интеграционный прогон трёх DAG. Никаких обращений к реальному API в unit-тестах.
Старые тесты прототипов находятся отдельно в `archive/research/` и запускаются
явной командой из README архива, а не как тесты готовой лабораторной.
