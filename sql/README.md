# Схемы и SQL

Будущие DDL и SQL по слоям (`ods`, затем `dds` и `marts`) и выбранным хранилищам.
Создавать после утверждения конкретной модели. Полную ER-модель DDS не
реализовывать в ЛР1. Для документных/объектных форматов использовать описание
в документации, не имитировать SQL там, где он не нужен.
