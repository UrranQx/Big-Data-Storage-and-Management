# Архив / отстойник

Здесь сохранены материалы исследования источника до реализации ЛР1.
Перенос вместо удаления выполнен 2026-10-15. Архив не является рабочим ETL
и не должен автоматически попадать в сборку, Airflow или тесты нового приложения.

- `research/` — все 28 прежних Python-файлов, их тесты и старые инструкции.
- `backups/` — локальный исходный ZIP, исключённый из Git.

Не считать файлы мусором, который можно безусловно удалять: они сохраняют
доказательства изученных случаев и полезные примеры. Не считать их и готовой
реализацией лабораторной. Для переноса решения в рабочий код сначала проверить
его применимость и ограничения.
