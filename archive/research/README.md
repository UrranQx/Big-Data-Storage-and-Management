# Исследовательские прототипы — не рабочая ЛР1

Все 28 Python-файлов из прежнего корня перенесены сюда без изменения содержимого.
Они оставлены вместе, чтобы сохранить взаимные импорты. SHA-256 записаны
в `inventory.json`. Старый корневой README сохранён в `LEGACY_USAGE.md`;
его команды и заявления относятся к прошлым исследованиям, а не новому ETL.

## Что здесь находится

- `collect.py` — ранний v1-клиент и пилотный сбор; `collect_all.py` — прототип
  полного сбора выбранной игры через v2 с опциональным v1-аудитом.
- `collect_games.py` — каталог; `rank_games*.py` — исследовательские рейтинги.
- `validate.py`, `test_collect*.py` — проверки и тесты этих прототипов.
- `probe_*.py`, `audit_*.py`, `inspect_*.py` и Minecraft-скрипты восстановления —
  разовые эксперименты, часто с фиксированными ID и путями снимков.

Не импортировать эти модули в новый рабочий код. Часть исследований выполняет
сетевые запросы при импорте; не запускать весь каталог или автоматический
импорт всех модулей. Ограничения источника читать в корневых документах.

## Как сохранить совместимость старых команд

Все команды выполняются **из корня репозитория**, потому что пути `data/...`
в прототипах относительны к текущему каталогу. Для скрипта достаточно добавить
архивный путь к имени файла, сохранив прежние аргументы:

```powershell
python archive/research/collect_all.py --help
python archive/research/validate.py --help
```

Эти две команды показывают справку, а не запускают сбор. Не запускать реальную
выгрузку без определения области, бюджета и нового пути снимка.

Только старые локальные unit-тесты, без обращений к источнику:

```powershell
python -m unittest discover -s archive/research -p "test_collect*.py" -v
```

Не менять текущий каталог на `archive/research/` для обычных исследовательских
команд: это изменит расположение ожидаемого `data/`.

Ограничитель клиента работает в пределах одного процесса. Бессрочный raw-кэш
служит продолжению снимка, а не получению свежих данных. SQLite/CSV — прежний
исследовательский экспорт, не одно из уже выбранных трёх хранилищ ЛР1.
