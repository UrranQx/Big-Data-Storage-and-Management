# Работа с архивом

Это отстойник исследовательских материалов. Не развивать здесь рабочую ЛР1.
Не подключать архив к DAG, Docker-образам или рабочему PYTHONPATH.
Чтение разрешено; автоматический запуск всех файлов запрещён: некоторые
исследования обращаются к API непосредственно при импорте модуля.

При необходимости запуска сначала прочитать конкретный скрипт и README.
Для нового кода использовать отдельные модули в `src/speedrun_etl/`.
Сохранять архив неизменным без необходимости; `inventory.json` содержит
контрольные суммы перенесённых Python-файлов. Исторические указания внутри
`LEGACY_USAGE.md` не переопределяют корневой `AGENTS.md` и текущий план.
