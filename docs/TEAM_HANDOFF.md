## Локальный запуск

Нужны Docker Desktop с Linux-контейнерами, Docker Compose и Python 3.11
для генерации локальной конфигурации. Первый запуск из корня проекта:

```powershell
python infra/configure.py
docker compose config --quiet
docker compose build init
docker compose up -d
docker compose ps
```

Собирается одна цель `init`; остальные Airflow-сервисы используют тот же образ.
Скрипт создаёт собственные `.env` и `infra/garage.local.toml` и отказывается
перезаписывать существующие настройки. UI — http://localhost:8080,
пользователь `admin`, пароль — локальный `AIRFLOW_ADMIN_PASSWORD`.

В передаче есть исходники и небольшие доказательства проверок, но нет Docker
volumes, полных ответов API или текущих контрольных точек сборщика. Успешные
запуски с компьютера автора не появятся в новом Airflow автоматически.
Сравнительные CSV относятся к стенду автора; повторные измерения на другом
компьютере могут отличаться.

Проверки без Speedrun.com:

```powershell
docker compose exec scheduler python -m unittest discover -s /opt/project/tests -v
docker compose exec -e ETL_INTEGRATION=1 scheduler python -m unittest discover -s /opt/project/tests -p test_storage_integration.py -v
```

Второй тест использует три локальных хранилища и отдельные тестовые пространства.
Сбор из сети запускать согласованно: два компьютера имеют независимые
ограничители запросов. Начать можно с малого Portal e2e из README; глобальную
очередь с историческими датами/ID автоматически не запускать.

## Совместная работа

Изменения делать в отдельной ветке: `git switch -c teammate/<task>`.
Удобные независимые задачи — анализ замеров и графики, оформление отчёта,
проверка демонстрации, подготовка SQL-примеров чтения ODS. DDS, витрины и
дополнительная инфраструктура относятся к следующим лабораторным.

Коммит сохраняет состояние реализации, а не обещает завершение текущего сбора.
На момент передачи каталог всех 52 102 игр проверен в трёх ODS. Minecraft
получил 46 247 ранов; после исправления пустого WR-ответа выполнение возобновлено.
Замеры Half-Life завершены, исходные результаты — `reports/lab1/measurements.csv`
и `benchmark_input.json`; графики формирует `reports/lab1/plot_results.py`.
