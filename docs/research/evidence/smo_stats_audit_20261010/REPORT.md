# Причина расхождения Super Mario Odyssey

В API v1 найдены три подтверждённых Any% полной игры без участников: `players: []`. Они учитываются статистикой игры, но отсутствуют в ответах лидерборда API v2.

| Ран | Дата | Время | Статус | Участники |
|---|---|---|---|---|
| [y6p5jo1m](https://www.speedrun.com/smo/runs/y6p5jo1m) | 2018-08-01 | PT1H14M3S | `verified` | `[]` |
| [z01ewg4y](https://www.speedrun.com/smo/runs/z01ewg4y) | 2019-05-30 | PT1H19M18S | `verified` | `[]` |
| [yj686v3z](https://www.speedrun.com/smo/runs/yj686v3z) | 2020-11-20 | PT1H31M59S | `verified` | `[]` |

- Any% в v1: **19274**; в v2: **19271**.
- Остальные пять полных категорий: **4228** в обоих API.
- Все подтверждённые полные забеги в v1: **23502** — совпадает с `totalRunsFG`.
- Сумма лидербордов v2: **23499**.

Для Any% прочитаны перекрывающиеся первые и последние страницы v1; пересечение подтверждает отсутствие разрыва посередине. Для каждого подозрительного забега дополнительно прочитаны три соседние страницы лидерборда v2, охватывающие его время. Проверена сортировка по времени. Множества ID внутри интервала совпали с v1 за исключением именно этого рана без участников. Результаты — в `leaderboard_neighborhood_checks.json`. Карточки всех трёх ранов в v2 дополнительно подтверждают `orphaned: true` и `issues: ["no players"]`.

Статистика перепроверена после сверки (`after/raw/`). Исходные ответы с URL и временем сохранены в `raw/`, полный результат — `report.json`.

Факт отсутствующей привязки к участникам подтверждён публичными данными. Установить, были ли аккаунты удалены или участников удалили из ранов другим способом, по этим ответам нельзя. Точный SQL запроса сайта также недоступен; утверждение об INNER JOIN было бы предположением.

Для ETL лидерборд v2 нельзя использовать как единственный источник: записи v1 нужно добавлять по ID, сохраняя пустой список участников и исходный JSON, без выдумывания имени или страны раннера.
