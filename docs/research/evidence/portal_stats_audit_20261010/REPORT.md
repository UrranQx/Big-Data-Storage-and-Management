# Portal: два пропуска подтверждены как orphaned

| Ран | Категория | Дата | Время |
|---|---|---|---|
| [znrek39y](https://www.speedrun.com/portal/runs/znrek39y) | Inbounds | 2019-11-28 | PT18M39.270S |
| [y8r6rg5m](https://www.speedrun.com/portal/runs/y8r6rg5m) | Inbounds Legacy | 2020-11-25 | PT24M6.079S |

Обе записи сейчас имеют `status=verified` в v1 и пустой `players=[]`. Карточки v2 подтверждают `orphaned=true`, `issues=["no players"]`. Обе отсутствуют в уже полностью выгруженных verified-ранах v2.

Свежие конечные страницы v1 дали **16622** verified full-game, что совпадает со статистикой сайта. Полная выгрузка v2 содержит **16620**; свежие счётчики категорий с пропусками не изменились. Разница составляет ровно один ран Inbounds и один Inbounds Legacy.

Исторический кэш v1 использован только для поиска кандидатов. Каждая подозрительная карточка и количества категорий проверены свежими запросами. Исторические отличия кэша от текущих данных отдельно записаны в `historic_non_orphan_differences` отчёта; старый кэш не считается свежей выборкой.

Основной датасет не изменён: orphaned остаются исключёнными по решению пользователя. Полные доказательства — `report.json`, исходные ответы с URL и временем — `raw/`.
