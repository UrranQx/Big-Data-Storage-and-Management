# Сохранённые свидетельства исследования

Небольшие отчёты скопированы 2026-10-15 из локального `data/` без изменения
содержимого, чтобы они не потерялись при передаче проекта через Git.

- [Super Mario Odyssey](smo_stats_audit_20261010/REPORT.md) — три записи без игроков.
- [Portal](portal_stats_audit_20261010/REPORT.md) — две записи без игроков.
- [Minecraft](minecraft_java_stats_audit_20261010/REPORT.md) — архивная Combined,
  численное согласование разницы и ограничения восстановления ID.
- [Obsolete](research_20261010/obsolete_evidence.json) — локальные примеры
  сохранённых старых результатов вместе с текущими.

Рядом с тремя отчётами сохранены их небольшие `report.json`. Исходные ответы,
полные списки ID, SQLite/CSV и манифесты остаются в локальном `data/`, который
не включён в Git. Внутренние пути в отчётах относятся к этому локальному
расположению и старым именам исследовательских скриптов.
Отчёты описывают прошлые снимки, а не текущие показатели сайта.
