# 2. В каком из моих зачётов попробовать взять WR

[К карте идей](../../ANALYTICS_IDEAS.md)

## Задача

Помочь раннеру с несколькими PB выбрать дисциплину, в которую он готов вложить время ради мирового рекорда.

## Что показать

| Показатель | Зачем он нужен |
|---|---|
| Разрыв PB → WR в секундах и процентах | Сравнить требуемый шаг с уже наблюдавшимися улучшениями этого раннера |
| Длительность одного прохождения | Понять, сколько занимает завершённый ран в этом зачёте |
| Число разных активных соперников рядом с WR | Увидеть, насколько быстро цель может сдвинуться |
| Недавние PB игрока | Отличить давний единичный результат от серии близких публикаций |

Точечная диаграмма связывает требуемое улучшение с длительностью прохождения. Размер точки отражает поле, а в карточке доступны предыдущие шаги PB.

## Данные

На архиве можно сравнить величину разрывов и состав поля на дату среза. Для оценки текущей возможности нужны свежие сопоставимые наблюдения и достаточная история PB самого игрока. Разрывы и прошлые улучшения помогают выбрать кандидатов. Вероятность нового WR требует отдельной проверки.
