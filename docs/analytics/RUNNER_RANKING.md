# Как сравнивать достижения раннеров

[К карте идей](../../ANALYTICS_IDEAS.md)

## Реализованная первая версия: универсальность, 27 ноября

По выбору пользователя основной топ — **универсальность**, сумма лучших
результатов максимум в **десяти разных играх**. Это исследовательская оценка
достижений в имеющейся выборке, а не объективная шкала сложности игр.
[Открыть дашборд](http://localhost:8088/superset/dashboard/lab3-ranking/).
Рядом находятся отдельный топ по лучшему результату и медальная таблица.

### Баллы одного результата

В каждом сопоставимом сольном поле считаются один текущий PB на игрока,
расчётное место `RANK`, число игроков `N` и число равных результатов.
Поля включают игру, категорию, значимые переменные, таймер, направление
сравнения и наблюдаемую версию правил. Дополнительные платформенные копии
поля исключены; переменные платформы, разделяющие исходный зачёт, сохраняются.
Командные результаты не приписываются участнику как сольные.

`W` — число строго худших результатов, `T` — число равных результатов
**других** игроков. Формула:

```text
Перцентиль = 100 × (W + 0,5 × T) / (N − 1)
Баллы результата = 100 × (W + 0,5 × T) / (N − 1 + 20)
```

20 — выбранная консервативная поправка за малое поле, не выученный коэффициент
и не доверительная вероятность. По умолчанию учитываются поля от 10 человек;
в интерфейсе можно выбрать 2, 10, 30 или 100. Для единственного участника оценка
не рассчитывается. Ничьи дают половину сравнительного вклада, поэтому сотня
одинаковых первых мест не означает, что каждый обошёл всех остальных.

| Результат без ничьих | Баллы при поправке 20 |
|---|---:|
| 1-й из 2 | 4,762 |
| 2-й из 2 | 0 |
| 1-й из 10 | 31,034 |
| 1-й из 100 | 83,193 |
| 100-й из 10000 | 98,812 |

Первые две строки включаются только при минимуме поля 2. Нулевой балл второго
из двух говорит об отсутствии обойдённых соперников, а не о бесполезности или
лёгкости его достижения. Рядом остаются медали, исходный результат и условия.
Большие сообщества получают преимущество в этой оценке; без внешней проверки
сложности нельзя утверждать, что такое преимущество отражает трудность рана.
В таблице лучшего результата показаны альтернативные места при поправках
5 и 50; они относятся к лучшему результату, не к сумме десяти игр.

### Итог раннера

В каждой игре берётся максимум баллов по её зачётам. Затем складываются десять
лучших игровых вкладов: итог от 0 до 1000. Игрок может участвовать с меньшим
числом игр; отсутствующие вклады равны нулю. Одиннадцатая игра заменяет
одну из десяти, только если её лучший результат сильнее. Рядом видны названия
игр и каждый вклад. Само наличие нескольких игр одной серии не доказывает
разнообразия жанров или переноса навыка.

Места считаются по неокруглённым баллам с `RANK`; одинаковые баллы дают одинаковое
место. Выбор раннера применяется после общего ранжирования. Смена минимального
поля пересчитывает состав, лучшие зачёты, сумму и места. Медали считаются по
расчётным сольным местам в полях, прошедших тот же порог, а не по исходным местам
сайта; у этого отдельного режима сохраняется зависимость от числа подкатегорий.

### Длительность, плотность и обратные категории

Пять часов в GTA 100% нельзя сравнить с пятью часами другой категории только
по часам. В этой версии длительность не даёт бонуса. Для лучшего зачёта раннера
показаны значение результата, WR, относительное отставание, число игроков
в пределах 1% от WR, разрыв топ-10 с WR и медиана опубликованных завершений
для направления «меньше лучше». Это контекст для разбора, а не скрытые веса.

Для «больше лучше» порядок разворачивается до расчёта места. В данных есть
такие категории, но, например, Pou High Score кодирует в таймере величину
результата: её нельзя автоматически называть длительностью или выносливостью.
Поэтому таблица подписывает шкалу таймера и направление, а медиану завершений
для обратных категорий оставляет пустой. Плотность может быть следствием
округления или предела маршрута; она тоже не увеличивает баллы автоматически.

### Охват и воспроизводимость

На срезе 30 октября: 226943 профиля в опубликованной аналитике, 135022 с оценкой,
89763 без текущего подходящего сольного PB и 2158 только с полями меньше 10.
Профили без оценки доступны через поиск и имеют явный статус. Это не все
профили сырой ODS: расчёт использует только завершённые цепочки текущей витрины.
Отсутствие оценки не означает отсутствие достижений на сайте.

[SQL расчёта](../../infra/runner_ranking.sql) — один read-only запрос поверх
`speedrun_marts.pb`, `scope`, `player` и `context`. Он используется виртуальным
dataset Superset, поэтому читает текущую атомарно опубликованную сборку.
Основной архив не пересобирается и не изменяется ради нового представления.
Новые связи дашборда регистрируются штатной синхронизацией OpenMetadata.

Проверки выполняют настоящий SQL на временных PostgreSQL-таблицах: ничьи,
масштаб времени, обратное направление, малые поля, отсутствие PB, команды,
повторные подкатегории и платформы, ограничение десятью играми.
[Числа и топы](../../reports/lab3/runner_ranking10_20261127/validation.json).

Ниже сохранён более широкий исходный замысел: жанры, ретро, сила соперников,
сезоны и сравнение пары не объявляются реализованными этим рейтингом.

## Задача

Показать, как меняется ответ на вопрос «кто лучший», если выбирать призовые места, относительное достижение, широту портфеля или текущую форму.

## Что показать

| Режим | Показатель |
|---|---|
| Призовые места | Число первых, вторых и третьих мест по сопоставимым зачётам. Можно сопоставить олимпийский порядок и исследовательский вариант с весами. |
| Сила результата | Исходное место, расчётное место из N, доля обойдённых соперников и отставание от WR. |
| Мастерство в одной игре | Число зачётов с топ-10 или топ-1% и достаточным полем. Если есть история, показать и периоды лидерства. |
| Универсальность | Число игр с сильным результатом. Для каждой игры можно брать один лучший зачёт, чтобы число подкатегорий не задавало весь вклад. |
| Текущая форма | Улучшения PB и повторяемость сильных результатов за выбранный период. |
| Сравнение пары | Разрывы в общих зачётах с одинаковыми правилами. Уникальные достижения каждого остаются отдельными строками. |

100-й из 10 000 обошёл 9 900 соперников, а 2-й из 2 получил серебро и обошёл ноль из одного. Для сравнения можно показать место и долю рядом. Доля с учётом ничьих равна `(хуже + 0,5 × равные) / (N − 1)`, где в числителе только другие соперники. Для N = 1 видимо само место. В межигровом рейтинге полезно проверить, как меняется список при разных минимальных размерах поля.

## Данные

Для сравнения нужны сопоставимые таймеры, правила и одинаковое определение поля. Для оценки специализации отдельно показываем, что игрок предпочитает бегать и где достигает высоких мест.

- **Ретро.** Варианты фильтра — эпоха релиза или возраст игры на дату рана. Они отвечают на разные вопросы.
- **Жанры, серии и движки.** Нужен справочник с наблюдаемыми источниками и признаком неизвестной метки. Издания могут различаться по движку.
- **Типы категорий.** Цель прохождения и допустимость техник — отдельные признаки. Платформа и эмуляция относятся к наблюдаемому рану.

Для карьеры можно сравнить такие срезы между сезонами или посмотреть траекторию переходов. Анализ силы поля по результатам тех же соперников в других зачётах требует проверки, насколько эти сообщества связаны между собой. Для активности отдельно считаются уникальные раны, участие, подача и решения.
