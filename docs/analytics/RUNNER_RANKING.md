# Как сравнивать достижения раннеров

[К карте идей](../../ANALYTICS_IDEAS.md)

## Задача

Показать, как меняется ответ на вопрос «кто лучший», если выбирать призовые места, относительное достижение, широту портфеля или текущую форму.

## Что показать

| Режим | Показатель |
|---|---|
| Призовые места | Число первых, вторых и третьих мест по сопоставимым зачётам. Можно сопоставить олимпийский порядок и исследовательский вариант с весами. |
| Сила результата | Исходное место, расчётное место из N, доля обойдённых соперников и отставание от WR. |
| Мастерство в одной игре | Число зачётов с топ-10 или топ-1% и достаточным полем. Если есть история, показать и периоды лидерства. |
| Универсальность | Число игр с сильным результатом. Для каждой игры можно брать один лучший зачёт, чтобы число подкатегорий не задавало весь вклад. |
| Текущая форма | Улучшения PB и повторяемость сильных результатов за выбранный период. |
| Сравнение пары | Разрывы в общих зачётах с одинаковыми правилами. Уникальные достижения каждого остаются отдельными строками. |

100-й из 10 000 обошёл 9 900 соперников, а 2-й из 2 получил серебро и обошёл ноль из одного. Для сравнения можно показать место и долю рядом. Доля с учётом ничьих равна `(хуже + 0,5 × равные) / (N − 1)`, где в числителе только другие соперники. Для N = 1 видимо само место. В межигровом рейтинге полезно проверить, как меняется список при разных минимальных размерах поля.

## Данные

Для сравнения нужны сопоставимые таймеры, правила и одинаковое определение поля. Для оценки специализации отдельно показываем, что игрок предпочитает бегать и где достигает высоких мест.

- **Ретро.** Варианты фильтра — эпоха релиза или возраст игры на дату рана. Они отвечают на разные вопросы.
- **Жанры, серии и движки.** Нужен справочник с наблюдаемыми источниками и признаком неизвестной метки. Издания могут различаться по движку.
- **Типы категорий.** Цель прохождения и допустимость техник — отдельные признаки. Платформа и эмуляция относятся к наблюдаемому рану.

Для карьеры можно сравнить такие срезы между сезонами или посмотреть траекторию переходов. Анализ силы поля по результатам тех же соперников в других зачётах требует проверки, насколько эти сообщества связаны между собой. Для активности отдельно считаются уникальные раны, участие, подача и решения.
