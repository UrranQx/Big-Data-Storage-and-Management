# 3. В какой новой игре пригодится мой опыт

[К карте идей](../../ANALYTICS_IDEAS.md)

## Задача

Найти для раннера новые игры и зачёты по реальным переходам людей с похожим портфелем. Для каждого предложения показать, на каких наблюдениях оно основано.

## Что показать

- Карточку кандидата с общим исходным зачётом, числом похожих раннеров, переходов и сильных первых результатов в игре назначения.
- Сравнение доли переходов среди похожих игроков с базовой долей среди сопоставимых игроков за одинаковый срок. Минимальная поддержка защищает рейтинг от единичных переходов.
- Диаграмму потоков между играми, где рядом видны абсолютное число переходов и частота с поправкой на популярность назначения. Можно ограничить повторы одной франшизы и увидеть кандидатов из других сообществ.

## Данные

Для первого расчёта достаточно датированных сопоставимых результатов и идентификаторов участников. Портфели строятся из сведений, доступных до выбранной даты. На более поздних публикациях проверяется, насколько подбор предсказывает реальные переходы, насколько он разнообразен и как отличается от списка популярных игр.

Жанры, движки и серии требуют проверенных справочников. Игру можно рекомендовать по общим участникам ещё до такого обогащения.

### Карты сходства

| Объекты | Как сравнивать |
|---|---|
| Игры и зачёты | Пересечение участников с поправкой на размеры аудиторий. Отдельно можно проверить пересечение игроков с сильными результатами. |
| Раннеры | Портфели игр, доли разных зачётов и относительные результаты. |
| Раны | Сопоставимое отставание от лидера, шаг улучшения PB и наблюдаемые условия прохождения. |
| Страны, платформы, жанры и движки | Доли участия в общем наборе зачётов вместе с размером каждой группы и покрытием меток. |

Первый экран может содержать матрицу сходства и список соседей. Для карты в двух координатах можно отдельно исследовать PCA или UMAP и проверять исходное сходство соседей. Например, группировку Source-игр проверять на карте по общим участникам, а движком окрашивать уже построенную карту. Ограничения на использование данных для обучения моделей вынесены в заметку о демонстрации и источниках. [Работа об UMAP](https://arxiv.org/abs/1802.03426)
