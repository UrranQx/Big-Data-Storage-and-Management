# 9. Кого пригласить на близкую гонку

[К карте идей](../../ANALYTICS_IDEAS.md)

## Задача

Помочь организатору подобрать участников для гонки в конкретном зачёте и увидеть, где возможен большой разрыв.

## Что показать

- Матрицу пар по недавним сопоставимым результатам, медианному отрыву и разбросу времени.
- Для каждой пары период, число ранов, выбранный таймер и ограничения формата.
- На карточке пары несколько наблюдений, на которых основан вывод о близости. Объём выборки виден сразу.

## Данные

Архив позволяет сравнить опубликованные прохождения в одинаковых условиях. Для оценки разрывов на живом мероприятии понадобятся результаты сопоставимых прошлых гонок. Составы команд и соло-игроки сравниваются отдельно.
